# React + Vite Starter

The project is organized as two npm workspaces:

- `frontend/` — React application powered by Vite
- `backend/` — minimal Node.js HTTP API starter (`/api/health`)

## Getting started

Install dependencies from the repository root:

```bash
npm install
```

Start either workspace in a separate terminal:

```bash
npm run dev:frontend
npm run dev:backend
```

The frontend is served at http://localhost:5173 and the backend at http://localhost:3000.

## Production build

```bash
npm run build
```
